# Quantum Tunneling and Wave-Packet Dynamics Simulator

## Requirements

- Python 3.10 or newer
- A local environment with the packages in `requirements.txt`
- For automated validation, also install `requirements-dev.txt`

## Install and launch

From this project directory in PowerShell:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Streamlit prints a local URL (normally `http://localhost:8501`). Choose the
particle and barrier parameters in the sidebar and click **Run experiment**.
The packet center can start on either side of the barrier; momentum is directed
toward the barrier. The width and energy sweeps run independent time-dependent
simulations and can be disabled to reduce runtime. The app warns if the primary
propagation time is too short for the packet to separate from the barrier or if
substantial probability has reached the absorbing boundaries.

## Outputs

- **Animation:** the computed `|ψ(x,t)|²` and the real rectangular potential,
  with playback controls.
- **Density vs time:** a position-time heat map of the computed probability
  density.
- **Transmission sweeps:** measured transmission from repeated simulations,
  shown with a separately identified stationary-state benchmark.
- **Probability balance:** probability remaining in the grid, cumulative
  absorbing-boundary loss, and the balance residual.
- **CSV:** parameters, measured reflection/transmission, numerical resolution,
  absorbed probability, and packet-averaged stationary benchmark.

The precomputed rows in `sample_data/sample_results.csv` are generated by the
solver, not illustrative or hardcoded graph values. Regenerate them with:

```powershell
python generate_sample_data.py
```

## Tests

```powershell
python -m pip install -r requirements-dev.txt
python -m pytest
```

The tests check analytic barrier limits, free-packet group velocity,
probability balance, and agreement/convergence for a narrow-energy packet. The
benchmark in that test is the exact stationary rectangular-barrier formula
averaged over the initial Gaussian momentum distribution; see `REPORT.md` for
the assumptions and interpretation.

## Numerical controls and units

All quantities are dimensionless and `ℏ = 1`. The default mass defines the
mass unit; the configured spatial and energy units imply the time unit through
the Schrödinger equation. The packet's central momentum is
`p₀ = √(2mE₀)` and its initial spatial standard deviation is `σₓ`; its momentum
standard deviation is `1/(2σₓ)`. The app varies the mass, central energy,
barrier height/width, packet width, time step, grid size, and total propagation
time. Read `REPORT.md` before interpreting results.
